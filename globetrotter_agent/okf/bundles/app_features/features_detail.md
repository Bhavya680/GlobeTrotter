# Features Detail

- **Multi-stop trip creation**: Allows multiple cities in one single trip.
- **Itinerary sections**: Each stop is one section with a specific date range and budget.
- **Activity suggestions**: Shown dynamically when a city is selected.
- **Budget breakdown**: 5 distinct categories (Transport, Stay, Activities, Meals, Misc).
- **Budget vs Actual charts**: Features Chart.js bar chart and React Recharts donut chart.
- **Calendar view**: Month view and week view where trip events are shown as colored bars.
- **Community tab**: Supports posts, likes, comments, and trip linking.
- **Profile**: Contains editable info, saved destinations, and trip history.
- **Public itinerary**: Provides a shareable URL, read-only view, and a copy trip feature.
- **Admin panel**: Contains 4 tabs (Managing Users, Popular Cities, Popular Activities, User Trends + Analytics).
- **Trip statuses**: Automatically calculated from dates as upcoming / ongoing / completed.
- **Trip visibility**: A toggle to set trips as public or private.
