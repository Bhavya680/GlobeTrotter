# Navigation Flows

1. **"How do I create a trip?"** → Flow: Dashboard → Create Trip (Screen 4) → Itinerary Builder (Screen 5) → Itinerary View (Screen 9)
2. **"How do I add activities?"** → Flow: Itinerary Builder → Activity Search modal
3. **"How do I see my calendar?"** → Flow: Calendar View (Screen 11) via navbar
4. **"How do I share my trip?"** → Flow: Itinerary View → Share button → public URL
5. **"How do I find cities?"** → Flow: City Search (Screen 8) via search bar
6. **"How do I track spending?"** → Flow: Itinerary View (Screen 9) budget section
7. **"How do I edit my profile?"** → Flow: Dashboard → Profile (Screen 7)
8. **"How do I delete a trip?"** → Flow: Trip List (Screen 6) → Delete button → Confirmation modal
9. **"How do I view community posts?"** → Flow: Dashboard → Community (Screen 10)
10. **"How do I make a post?"** → Flow: Community (Screen 10) → Compose Post modal
11. **"How do I change my password?"** → Flow: Profile (Screen 7) → Settings → Account → Change Password
12. **"How do I view admin analytics?"** → Flow: Admin (Screen 12) → Analytics tab
13. **"How do I copy a public itinerary?"** → Flow: Itinerary View (Screen 9, public URL) → Copy Trip button
14. **"How do I log out?"** → Flow: Navbar → Profile dropdown → Logout
15. **"How do I add a stop to a trip?"** → Flow: Itinerary Builder (Screen 5) → Add Stop button
