# GlobeTrotter Overview

- **What GlobeTrotter is**: An end-to-end travel planning platform.
- **Core User Journey**: Register → Create Trip → Build Itinerary → Track Budget → Share → Explore Community.
- **Vision Statement**: Personalized, intelligent, collaborative travel planning.
- **Who uses it**: Individual travelers, travel enthusiasts, budget-conscious explorers.
- **Platform type**: Web app (desktop and mobile responsive), PHP/MySQL backend.
