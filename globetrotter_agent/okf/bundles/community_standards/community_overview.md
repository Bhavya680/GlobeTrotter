# Community Overview

- **What it is**: A space for users to share travel experiences.
- **Types of posts**: trip reports, activity reviews, destination tips, travel questions.
- **Trip Links**: Posts can be linked to public trips via an optional field.
- **Interaction**: Features include likes, comments, and sharing.
- **Visibility**: All community posts are public (visible to non-logged-in users too).
- **Moderation**: Content is user-generated; reported content is reviewed by admins.
