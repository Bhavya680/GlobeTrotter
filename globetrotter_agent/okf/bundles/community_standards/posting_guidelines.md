# Posting Guidelines

- **Clarity**: Give it a clear, descriptive title (e.g., city/trip/experience).
- **Details**: Include specific details (what you did, how much it cost, when you went).
- **Links**: Link to your trip itinerary if it's public (adds credibility).
- **Tags**: Use tags to make your post discoverable (city names, activity types, trip style).
- **Limits**: Minimum content: 20 characters; maximum: 2000 characters.
- **Tone**: Must be helpful, honest, respectful.
- **Encouraged**: Photos via description, budget tips, honest reviews.
- **Discouraged**: Vague posts, spam, promotional content.
