# Cost Index Guide

- **Scale**: 1.0 (very budget) to 10.0 (very expensive).
- **Mapping**:
  - 1-3 = backpacker paradise
  - 4-5 = budget-friendly
  - 6-7 = mid-range
  - 8-9 = pricey
  - 10 = luxury destination
- **Daily budget estimates per cost index level (in USD)**: 
  - Index 2.0: ~$30/day
  - Index 5.0: ~$75/day
  - Index 8.0: ~$150+/day
- **Factors that affect cost**: Accommodation type, season (peak vs. off-peak), and current exchange rate.
- **How the agent should use cost_index**: Use it to answer "Is X affordable?" by mapping the user's stated budget against the index.
