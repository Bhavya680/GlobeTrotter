# Account Help

- **Registration**: Fields include first name, last name, email, phone, city, country, photo.
- **Log in**: Requires email + password.
- **Password requirements**: Min 8 chars, 1 uppercase, 1 number.
- **Update profile**: Go to Profile settings.
- **Change photo**: Click on photo in settings to upload.
- **Change password**: Settings → Account → Change Password.
- **Saved destinations**: Star/unstar cities to save them to your profile.
- **Delete account**: Settings → Delete Account (must type email to confirm).
- **Language**: Setting changes display UI only, does not translate user content.
- **Privacy settings**: Controls the default trip visibility toggle for new trips.
