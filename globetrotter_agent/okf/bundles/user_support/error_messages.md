# Error Messages

- **"Invalid email or password"** → Check email spelling, check caps lock.
- **"Email already registered"** → Use forgot password or log in with existing account.
- **"Date must be in the future"** → Trip start date cannot be in the past.
- **"End date must be after start date"** → Fix the date order.
- **"File too large"** → Photo must be under 2MB.
- **"Invalid file type"** → Only JPG, PNG, WEBP supported for photos.
- **"This itinerary is private"** → User set trip to private, share link won't work for others.
- **"Access denied"** → Admin-only area, requires admin role.
- **"Budget cannot be negative"** → Enter a positive number.
- **API errors**: If the page shows a loading error, advise the user to try refreshing.
