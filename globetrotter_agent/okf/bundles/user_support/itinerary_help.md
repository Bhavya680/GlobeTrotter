# Itinerary Help

- **Difference**: Create Trip is basic info; Itinerary Builder is the detailed plan.
- **Section**: One "section" in the builder equals one stop/city.
- **Add activities**: Use the '+ Add Activity' button which opens a search modal.
- **Remove activities**: Click the trash icon on the activity.
- **Auto-save**: The builder auto-saves every change (look for the "Saved ✓" indicator).
- **Date ranges**: A stop's date range must fall within the overall trip dates.
- **Budget per stop**: Covers expenses localized to that city.
- **Notes**: Users can add notes to a stop, accommodation details, and transport notes between stops.
- **Views**: The builder view is for editing; the itinerary view is a cleaner read-only presentation.
