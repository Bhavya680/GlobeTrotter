# Trip Management Help

- **Creating a trip**: Required fields (name, dates); optional (description, photo, stops).
- **Trip statuses**: Upcoming / ongoing / completed (auto-calculated from today's date).
- **Edit a trip**: Click the Edit button to open the pre-filled Create Trip form.
- **Delete a trip**: Go to My Trips → Delete → confirm modal.
- **Add/remove stops**: Can be done after creation in the builder.
- **Reorder stops**: Drag and drop in the Itinerary Builder.
- **Visibility**: Use the Public/Private toggle.
- **Deletion impact**: Deleting a trip cascades to remove all stops and activities.
- **Calendar view**: Switch to Calendar tab to view trip dates visually.
- **Copying**: You can copy someone else's public itinerary via the 'Copy Trip' button.
