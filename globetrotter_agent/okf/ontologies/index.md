# Ontologies

Ontology files are JSON documents that define the structured entity types, their properties, and relationships in Globe Trotter.

- [Travel Entities](/ontologies/travel_entities.json): Defines User, Trip, TripStop, Activity, etc.
- [Activity Categories](/ontologies/activity_categories.json): Taxonomy of the 6 activity categories.
- [Region Taxonomy](/ontologies/region_taxonomy.json): Defines regions and their countries.
- [Budget Categories](/ontologies/budget_categories.json): Defines the 5 budget fields.
