# Content Moderation

- **Flags for removal**: hate speech, spam, illegal activity references, doxxing.
- **Gray areas**: strong opinions about places, negative but honest reviews.
- **Gray area handling**: keep negative honest reviews, remove personal attacks.
- **User reports**: users can report posts, which go to an admin queue.
- **Admin action workflow**: review → remove if violating → warn user → suspend repeat violators.
- **Appeal process**: email admin (admin@globetrotter.com).
