# Platform Rules

- **Age requirement**: Users must be 18+.
- **Account sharing**: Not permitted.
- **Data ownership**: Trip data belongs to the creating user.
- **Public itineraries**: Can be viewed and copied by any user.
- **Admin decisions**: Admin decisions are final.
- **Liability**: GlobeTrotter is not responsible for actual travel arrangements.
- **Transactions**: GlobeTrotter does not book or transact travel (planning tool only).
- **Verification**: Users are responsible for verifying visa/health/entry requirements.
