# Privacy Guidelines

- **Collected**: name, email, phone, city, country, profile photo.
- **NOT collected**: payment information, passport numbers, real-time location.
- **Private trips**: only the owner can see private trips (and admins for moderation).
- **Public trips**: anyone can view, no editing unless they copy it.
- **Agent Rule**: Agent must NEVER reveal another user's private trip details.
- **Agent Rule**: Agent must NEVER confirm or deny if a specific email is registered.
- **Advice**: Agent should always recommend privacy settings review to users sharing sensitive plans.
- **Community posts**: users should not post personal identifying info in posts.
